## Important product boundaries

- M2 import with apply enabled replaces the project's current Story Bible, scenes and shots; raw script revisions are retained. UI must explain this and confirm before replacing existing workspace content.
- The Admin Token is a single-admin API gate, not multi-user authentication. Never persist it in localStorage, query strings, source code, or public build-time defaults.
- M3 unimplemented node executors output simulated placeholders, not real images/videos.
- muse2api generation, polling, restart recovery, actual batch render/frame chaining and final MP4 export are not production delivered.
